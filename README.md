## 简介
这是一个专门针项目集成管理工程师学习使用的系统，能够播放视频、教材、知识点总结，仅限个人学习使用，切勿商业化使用，win、和 mac都能使用，需要安装python3

## 创作背景
在职产品狗备战2027年中项，但是市面上没有好用的学习系统或者材料，所以趁摸鱼时间手搓了一个符合我学习需求的自用系统，并分享给有需要的人，目前没有后续更新、扩展科目的计划。

## 运行方法
### win
在**study**文件夹中运行终端，执行以下命令
```
python server.py

 ```
### mac
在**study**文件夹中运行终端，执行以下命令
```
python3 server.py

 ```
